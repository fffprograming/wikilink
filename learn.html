LESSON 01 / 問題ID 0063f1377563

文学賞を「橋」にして考える

お題：中村光夫
本文リンクをちょうど2回たどって到達できるのは？

考えるヒント

人名から別の作品へつなぐときは、その人の著作だけでなく、関わる賞や文学の分類を候補にします。選択肢をいったん隠して「人物 → 賞 → 作品」という形を考えてみてください。

答えと考え方を読む

中村光夫 → 芥川龍之介賞 → 感傷旅行

中村光夫 → 芥川龍之介賞 → 感傷旅行という経路です。ここでの発見は、人物と作品の関係が「作者と著作」に限られないこと。賞の記事を間に置けば、人物から別の作者の作品へ話題が移ります。

間違えやすいポイント

お題の人物が書いた作品を選ぶ問題ではありません。「直接関係があるか」ではなく、間に入る記事を含めた2本のリンクを検討します。

記事を開いて確かめる

中村光夫の記事で芥川龍之介賞に触れる箇所を探し、賞の記事では感傷旅行の掲載箇所と、その前後の文脈を読みましょう。

出典：上記の各 Wikipedia 記事へのリンク。経路は収録データから掲載しています。本文の転載ではなく、本サイトの推理・読解ガイドです。記事の編集・改名によって現在の経路が変わる場合があります。

LESSON 02 / 問題ID 7c577d384364

企業から、競技の世界へ

お題：ボーダフォン
本文リンクをちょうど2回たどって到達できるのは？

考えるヒント

企業名を見たら、製品だけでなく、支援する活動や競技も中継候補になります。異なる分野の選択肢を、名前の印象だけで除外しないで考えます。

答えと考え方を読む

ボーダフォン → フォーミュラ1 → F1グランプリ

ボーダフォン → フォーミュラ1 → F1グランプリという経路です。企業から競技へ話題を移せると、その競技の記事から別の関連項目に進めます。「同じ業界にある言葉」を探すだけでは気づきにくい経路です。

間違えやすいポイント

「F1グランプリ」のように短いタイトルは、名前の印象と実際の記事の対象が一致するとは限りません。正解後に冒頭を読み、何についての記事か確かめてから、つながりを説明してみてください。

記事を開いて確かめる

ボーダフォンの記事でフォーミュラ1へのリンクを探し、次にフォーミュラ1の記事内でF1グランプリへのリンク先を開きます。表示される文字とリンク先の記事名が違う場合にも注目します。

LESSON 03 / 問題ID e9969cdb55d4

学校を経由する、意外な文学の経路

お題：夏目漱石
本文リンクをちょうど2回たどって到達できるのは？

考えるヒント

作家の名前からは作品を連想しがちですが、経歴に出てくる学校も候補になります。「人物 → 学校 → 作品」という形があり得るかを考えてみましょう。

答えと考え方を読む

夏目漱石 → 第一高等学校 (旧制) → 伊豆の踊子

夏目漱石 → 第一高等学校 (旧制) → 伊豆の踊子という経路です。経路を知ると、人物の伝記と作品の記事の間に、学校という別の視点を挟めることがわかります。

間違えやすいポイント

この正解は「伊豆の踊子は夏目漱石の作品」という意味ではありません。リンクで2回つながることと、著者であることは別です。経路の矢印は、因果関係や著者関係を証明しません。

記事を開いて確かめる

夏目漱石の記事から学校の項目へ進み、学校の記事で作品名がどんな文脈に出てくるかを確認します。最後に作品の冒頭も読み、リンクのつながりと作品自体の説明を区別しましょう。

次の問題で使う、3つの手順

  1. まずお題から中継候補を考える。作品・賞・学校・競技など、固有名詞を一つ挟んでみる。
  2. その候補から選択肢へ、もう1本のリンクがありそうか考える。
  3. 正解後は両方の記事を読み、リンクがある理由を自分の言葉で説明する。

知らない固有名詞があっても、外れた問題の中継記事を一つ覚えれば次の手がかりになります。ゲーム内の「最近の回答を振り返る」から、解いた経路を読み直せます。
